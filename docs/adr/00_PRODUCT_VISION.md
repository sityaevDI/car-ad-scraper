# Автомобильный агрегатор — Product Vision

## 1. Цель

Создать агрегатор объявлений автомобилей, который не просто объединяет объявления из разных источников, а формирует собственное представление о рынке:

- текущие цены;
- медианная/средняя рыночная цена;
- отклонение конкретного объявления от рынка;
- история изменения цены;
- время нахождения объявления на рынке;
- появление/исчезновение объявлений;
- статистика по модели, поколению, году, пробегу и другим параметрам;
- персональные сохранённые поиски и уведомления.

Существующий scraper считается Proof-of-Concept. Его код не должен ограничивать новую архитектуру. Допускается частичная или полная переработка.

## 2. Главный принцип

Scraping — это инфраструктурный механизм получения данных, а не основной продукт.

Пользователь должен мыслить категориями:

`Search → Results → Market price → Listing history → Alerts`

а не:

`Search existing DB → отдельно Scrape`.

Если данных недостаточно или они устарели, система сама предлагает/запускает обновление.

## 3. Источники

Планируемые источники:

1. Polovni Automobili — Сербия.
2. MojAuto — Сербия.
3. AutoScout24 — Европа.
4. Autoplius — Литва.
5. Otomoto — Польша.
6. Другие источники в будущем.

Каждый источник реализуется как независимый adapter/plugin.

## 4. Основные пользовательские ценности

### Найти машину

Пользователь задаёт:
- марку;
- модель;
- поколение;
- год;
- цену;
- пробег;
- двигатель;
- топливо;
- коробку;
- кузов;
- источник/страну;
- дополнительные параметры.

### Понять, выгодна ли цена

Для объявления показывается:
- цена объявления;
- оценка рыночной цены;
- отклонение в процентах;
- количество сопоставимых объявлений;
- диапазон рынка;
- confidence.

### Следить за рынком

Пользователь может:
- сохранить поиск;
- отслеживать объявления;
- получать уведомления о новых объявлениях;
- получать уведомления о снижении цены;
- видеть историю рынка.

## 5. Нецелевые задачи MVP

Не делать в MVP:
- мобильное приложение;
- ML-прогноз стоимости;
- идеальное автоматическое определение комплектации;
- идеальное определение поколения для всех моделей;
- десятки источников;
- realtime scraping;
- сложную рекомендательную систему;
- полноценную рекламную платформу;
- микросервисную архитектуру.
